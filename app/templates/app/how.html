System Overview

Our project is a secure electronic voting system designed to protect voter privacy, prevent duplicate voting, and ensure transparent final result publication without exposing individual ballot choices.

Core Idea

Each voter is verified using a salted Aadhaar or VID-based identity check. After verification, the voter can cast an encrypted ballot. The ballot remains encrypted during storage and aggregation.

Only the final combined result is decrypted once at the end of the election. Individual votes are never shown in plaintext.

Voter Authentication

What We Use

  • VID or Aadhaar-based identity verification
  • Salted hashing for identity protection
  • Eligibility validation before voting
  • No raw Aadhaar number stored as plaintext

Why It Matters

  • Prevents duplicate voting
  • Protects voter identity from direct exposure
  • Maintains separation between voter and ballot
  • Improves privacy compared to storing plain identity data

Homomorphic Encryption

Our system uses additive homomorphic encryption so vote totals can be computed without reading individual votes.

How Encryption Works

When a voter submits a ballot, the selected choice is converted into an encoded form and encrypted using the election’s public key.

Encrypted ballots can be aggregated mathematically, and only the final combined tally is decrypted with the private key after voting ends.

Ballot Encryption
Each vote is encrypted before storage
Encrypted Aggregation
Votes are added while still encrypted
Final Decryption
Only the final result is decrypted once

Blockchain Audit Layer

Why Blockchain Is Used

Blockchain is used in our project as an immutable audit layer. It helps ensure that recorded vote data and election actions cannot be tampered with after submission.

What It Provides

  • Immutable storage record
  • Transparent election audit trail
  • Protection against vote modification
  • Trust in final result publication

What It Does Not Do

  • It does not reveal individual votes
  • It does not store voter identity in readable form
  • It does not replace encryption
  • It does not expose ballot-voter mapping

Voting Process

1

Voter Verification

The voter is validated using Aadhaar or VID-related identity logic protected with salted hashing.

2

Ballot Creation

The selected candidate is encoded into the ballot format required for encrypted tallying.

3

Vote Encryption & Storage

The ballot is encrypted and stored securely, with blockchain support for immutable recording.

4

One-Time Final Tally

After the election closes, encrypted votes are aggregated and the final total is decrypted once.

Security Guarantees

Privacy Protection

  • No plaintext vote storage
  • No direct exposure of voter identity in ballot data
  • Encrypted votes remain protected until tally
  • Final result only is revealed

Integrity Assurance

  • Duplicate voting is prevented
  • Votes cannot be altered after recording
  • Election actions are auditable
  • One-time tally reduces repeated result manipulation risk

Technical Implementation

The system uses an additive homomorphic encryption approach so encrypted ballots can be combined without exposing individual selections.

  • Key Generation: Election-specific public/private key pair
  • Ballot Encryption: Vote encoded and encrypted before storage
  • Final Tally: Aggregate decrypted only once after election closure

Voter authentication is based on identity verification using salted hashing to reduce exposure of sensitive identifiers.

  • Identity Protection: Salted hash used instead of raw identity storage
  • Eligibility Check: Only verified voters are allowed to vote
  • Duplicate Prevention: One voter can cast only one valid ballot per election

Blockchain is integrated to provide an immutable record of election-related data and improve trust in result integrity.

  • Immutable Logging: Votes and results are protected from later tampering
  • Auditability: Election process can be traced for verification
  • Transparency: Final result publication is supported by trustworthy records

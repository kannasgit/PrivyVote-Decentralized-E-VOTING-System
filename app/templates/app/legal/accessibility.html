Our Accessibility Goal

We aim to make the voting platform easier to use for people with visual, motor, and cognitive challenges by providing readable layouts, simple navigation, keyboard-friendly interaction, and clear instructions.

Visual Accessibility

Better readability and easier interface visibility

  • Readable color contrast
  • Clear text hierarchy
  • Large and readable buttons
  • Simple page structure
Keyboard Accessibility

Easier navigation without depending only on a mouse

  • Keyboard-friendly navigation
  • Accessible forms and buttons
  • Logical page flow
  • Reduced interaction complexity
Motor Accessibility

Easier controls for users with limited movement precision

  • Large click areas
  • Simple form interaction
  • Clear button placement
  • Reduced unnecessary steps
Cognitive Accessibility

Clear content and understandable user flow

  • Simple language
  • Step-by-step guidance
  • Clear labels and instructions
  • Minimal confusion during voting
Device Support

PrivyVote is designed to work across common device types.

Desktop

Suitable for modern desktop browsers

Mobile

Responsive layout for smaller screens

Tablet

Readable and touch-friendly interface

Language and Clarity

We focus on making the interface easy to understand.

  • Simple page wording
  • Clear action labels
  • Consistent navigation
  • Reduced interface clutter
Help and Support

Users can report problems or ask for help through the contact page.

  • Guidance: Clear instructions are provided in key steps
  • Support: Accessibility concerns can be reported through the contact form

# 🗳️ PrivyVote – Decentralized E-Voting System

> A secure and transparent blockchain-based voting platform developed as our Final Year Project.

## 📌 Project Overview

PrivyVote is a decentralized electronic voting system designed to address the limitations of traditional voting methods, such as lack of transparency, susceptibility to tampering, and dependence on centralized authorities. By leveraging blockchain technology, the system ensures that votes are immutable, verifiable, and securely recorded.

The project was developed as part of our **Bachelor's Final Year Project** to explore the practical application of blockchain in building trustworthy digital governance systems.

---

## 🎯 Objectives

* Eliminate vote manipulation through blockchain immutability.
* Ensure transparency in the election process.
* Enable secure voter authentication and authorization.
* Maintain a decentralized and tamper-resistant voting infrastructure.
* Provide a user-friendly interface for administrators and voters.

---

## ✨ Key Features

* 🔐 Secure voter registration and authentication
* 🪪 OTP-based identity verification
* 🗳️ One person, one vote mechanism
* ⛓️ Blockchain-backed vote storage
* 👨‍💼 Admin dashboard for election management
* 📊 Real-time vote tallying and result generation
* 🔍 Transparent and auditable election records
* 🌐 Web-based responsive user interface

---

## 🏗️ System Architecture

The system consists of the following major modules:

### 1. User Authentication Module

Handles voter registration and login processes.

### 2. OTP Verification Module

Verifies voter identity before vote casting.

### 3. Election Management Module

Allows administrators to create and manage elections.

### 4. Voting Module

Enables eligible voters to cast their votes securely.

### 5. Blockchain Module

Records voting transactions in an immutable ledger.

### 6. Result Management Module

Computes and displays election results transparently.

## 🚀 Getting Started

### Prerequisites

* Python 3.x
* Node.js and npm
* Ganache
* MetaMask browser extension

### Installation

Clone the repository:

```bash
git clone https://github.com/kannasgit/PrivyVote-Decentralized-E-VOTING-System.git
cd PrivyVote-Decentralized-E-VOTING-System
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Configure environment variables:

Create a `.env` file and add the necessary credentials:

```env
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_PHONE_NUMBER=your_twilio_phone_number
```

Run the application:

```bash
python app.py
```
